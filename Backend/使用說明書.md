## 1. 系統概述

Lucku 後台管理系統是一套基於 Web 的 B2C 平台管理工具，主要功能涵蓋：

- **產品業務**：產品管理、產品分類、產品規格組合
- **卡片業務**：卡片分類管理、卡牌上架、抽卡預設排序
- **訂單業務**：訂單處理、物流管理、線下/日曆訂單
- **用戶業務**：用戶管理、會員等級
- **店鋪運營**：Banner、客服、常見問題、兌換設置
- **支付渠道**：Stripe 支付配置
- **系統管理**：管理員/角色權限、操作日誌

## 2. 登入與首頁

### 2.1 登入

訪問後台網址，輸入管理員帳號和密碼即可登入。

### 2.2 首頁儀表板

登入後預設進入儀表板，顯示：

- **銷售方向分析**：各類卡片的銷售趨勢
- **訂單分析**：訂單量、金額統計
- **首頁數據**：總訂單數、總用戶數、總銷售額等

## 3. 權限管理

### 3.1 角色管理

**功能路徑**：權限管理 → 角色列表

管理系統中的角色（權限組），每個角色可以擁有不同的功能權限。

| 操作 | 說明 |
|------|------|
| 新增角色 | 建立新角色，分配權限 |
| 編輯角色 | 修改角色名稱及權限範圍 |
| 刪除角色 | 刪除不再使用的角色（系統管理員角色不可刪除） |

> 權限選項來源於系統菜單配置，勾選即代表該角色擁有對應功能的操作權。

### 3.2 管理員管理

**功能路徑**：權限管理 → 管理員列表

管理可以登入後台的系統管理員帳號。

| 操作 | 說明 |
|------|------|
| 新增管理員 | 填寫帳號、密碼、信箱、手機號，選擇角色 |
| 編輯管理員 | 修改管理員資訊及所屬角色 |
| 刪除管理員 | 停用/刪除管理員帳號 |

## 4. 產品管理

產品管理包含產品的完整生命週期管理，從分類設定到產品上架及規格組合配置。

### 4.1 產品分類管理

**功能路徑**：產品管理 → 分類列表

管理產品分類，每個產品必須歸屬於一個分類。

| 欄位 | 說明 |
|------|------|
| 分類名稱 | 中/英文名稱 |
| 分類圖片 | 分類展示圖 |
| 排序 | 分類顯示順序 |
| 狀態 | 啟用/停用 |

| 操作 | 說明 |
|------|------|
| 新增/編輯分類 | 填寫分類資訊 |
| 刪除分類 | 刪除分類（軟刪除） |

### 4.2 產品列表

**功能路徑**：產品管理 → 產品列表

管理所有上架產品。

| 欄位 | 說明 |
|------|------|
| 產品名稱 | 中/英文名稱 |
| 產品圖片 | 展示圖檔（支援多圖相簿） |
| 產品價格 | 售價 |
| 產品成本 | 成本價 |
| 庫存數量 | 剩餘庫存 |
| 所屬分類 | 關聯的產品分類 |
| 標籤 | 產品標籤分類 |
| 狀態 | 啟用/停用 |

| 操作 | 說明 |
|------|------|
| 新增產品 | 填寫資訊 + 上傳圖片 + 選擇標籤 |
| 編輯產品 | 修改產品資訊 |
| 刪除產品 | 軟刪除產品 |

### 4.3 產品規格管理

產品支援多規格組合，例如同一產品有不同的尺寸或材質版本。

**規格分類管理**

**功能路徑**：產品管理 → 規格分類

定義產品的規格屬性名稱，如「尺寸」、「顏色」、「材質」等。

| 操作 | 說明 |
|------|------|
| 新增規格分類 | 建立新的規格屬性名稱 |
| 編輯規格分類 | 修改規格名稱 |
| 刪除規格分類 | 刪除規格屬性 |

**規格值與組合**

在新增/編輯產品時可以：
1. 為產品綁定多個規格分類
2. 每個規格分類下設定具體規格值（如尺寸：S、M、L）
3. 建立規格組合，每組組合可獨立設定：
   - **價格**：該規格的售價
   - **庫存**：該規格的獨立庫存數量
   - **圖片**：該規格對應的產品圖

> 規格組合讓同一個產品可以有多種販售選項，用戶在 APP 下單時可選擇指定規格。

## 5. 卡片管理

卡片管理是系統的核心功能，採用「分類（卡池）→ 卡牌」的兩層結構。

### 4.2 卡池管理

**功能路徑**：卡片管理 → 卡池管理

管理卡池分類（每個分類即為一個「卡池」，用戶在 APP 中抽取的即為卡池）。

| 欄位 | 說明 |
|------|------|
| 分類名稱 | 中/英文名稱 |
| 分類圖片 | 卡包展示圖 |
| 卡片數量 | 該分類下包含的卡牌數量 |
| 抽卡價格 | 抽一次卡所需的金額 |
| 狀態 | 啟用/停用 |

| 操作 | 說明 |
|------|------|
| 新增/編輯分類 | 填寫分類資訊 |
| 刪除分類 | 刪除分類（軟刪除） |
| 查看卡片 | 查看該分類下的所有卡牌 |

### 4.3 卡牌管理

**功能路徑**：卡片管理 → 卡片列表

管理所有卡牌（每個卡牌屬於一個卡包分類）。

| 欄位 | 說明 |
|------|------|
| 卡牌名稱 | 中/英文名稱 |
| 卡牌圖片 | 展示圖檔 |
| 卡牌稀有度 | N / R / SR / SSR |
| 卡牌價格 | 售價 |
| 庫存數量 | 剩餘庫存 |
| 所屬分類 | 關聯的卡包分類 |
| 狀態 | 啟用/停用 |

| 操作 | 說明 |
|------|------|
| 新增卡牌 | 填寫資訊 + 上傳圖片 + 選擇標籤 |
| 編輯卡牌 | 修改卡牌資訊 |
| 刪除卡牌 | 軟刪除卡牌 |

### 5.4 抽卡預設排序

**功能路徑**：抽卡管理 → 抽卡預設

管理用戶抽卡時的卡片出現順序。

| 操作 | 說明 |
|------|------|
| 自動初始化 | 系統自動為所有卡包建立預設排序 |
| 編輯排序 | 拖動卡片調整出現順序 |
| 隨機打亂 | 系統隨機排列卡片順序 |
| 鎖定/解鎖 | 鎖定後禁止修改排序 |

> **規則**：系統會自動將已無庫存的卡片排在前面，有庫存的排在後面，各自範圍內可自訂順序。

## 10. 常見問題

### Q1：如何新增一個產品？

1. 先確保已建立對應的「產品分類」（若無則先至分類列表新增）
2. 至「產品列表」點擊新增，填寫產品名稱、價格、庫存等資訊
3. 上傳產品圖片，選擇所屬分類及標籤
4. 若產品有多種規格（如不同尺寸），可在「規格分類」中先建立規格，然後在產品編輯中綁定規格組合

### Q2：如何新增一個新的卡包？

1. 先確保已建立對應的「卡片系列」
2. 至「分類管理」新增分類，選擇系列、填寫名稱、設定抽卡價格
3. 至「卡片列表」新增卡牌，選擇剛建立的分類，填寫卡牌資訊
4. 至「抽卡預設」點擊自動初始化，系統自動為該卡包建立排序

### Q2：如何配置 Stripe 支付？

1. 至 Stripe Dashboard 獲取 Publishable Key 和 Secret Key
2. 在後台「店鋪管理」→ Stripe 設置 中填入金鑰
3. 選擇環境為 sandbox 進行測試，確認無誤後改為 live

### Q3：忘記管理員密碼怎麼辦？

可透過資料庫直接重置，或在「管理員編輯」頁面中由超級管理員修改密碼。

### Q4：訂單狀態不對怎麼辦？

管理員可在「訂單列表」中手動操作：
- 未支付 → 確認支付（線下收款後手動確認）
- 未發貨 → 添加物流
- 未完成 → 確認收貨
